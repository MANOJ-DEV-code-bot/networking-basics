# 🌐 Networking Basics

## About This Project
This project contains my learning notes about computer networking fundamentals.

## 📚 Topics Covered

### 1. What is Computer Networking?
Computer networking is the connection of two or more devices to share data and resources.

### 2. Types of Networks
- LAN – Local Area Network
- WAN – Wide Area Network
- MAN – Metropolitan Area Network
- PAN – Personal Area Network

### 3. Networking Devices
- Router
- Switch
- Hub
- Modem
- Access Point

### 4. IP Address
An IP address is a unique logical address used to identify a device on a network.

- IPv4 – 32 bits
- IPv6 – 128 bits

### 5. Networking Protocols
- TCP
- UDP
- HTTP
- HTTPS
- DNS
- DHCP
